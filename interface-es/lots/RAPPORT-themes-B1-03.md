## Doublons acceptés

- Mêmes mots allemands repris d'un niveau à l'autre, même réponse que la carte déjà posée :
  1399 Semester, 1460 Gehalt, 1611 Führerschein, 1612 Ampel, 1613 Stau.
- 1350 Kugelschreiber « el bolígrafo (de tinta) » : **Stift (A1) porte déjà « el bolígrafo »**.
  La précision n'évite le doublon que par la forme ; il vaudrait mieux que Stift devienne
  « el lápiz, el bolígrafo (cualquier cosa para escribir) ».
- 1339 Mathe / 1351 Mathematik : l'espagnol d'Amérique n'a pas de forme courte commune
  (« mates » est d'Espagne) ; Mathe = « las matemáticas (forma corta, coloquial) ».
- 1661 Geschwindigkeitsbeschränkung « el límite de velocidad » : Geschwindigkeitsbegrenzung (même
  thème, autre lot) recevra forcément la même réponse — l'espagnol n'a qu'un mot.

## Sources à signaler

- 1305 Folie (thème Schule) : l'exemple parle de film alimentaire, pas du transparent de
  rétroprojecteur ou de la diapositive attendus dans ce thème. Traduit selon l'exemple.
- 1467 Werk, 1468 Führung, 1479 Leiter, 1627 Klingel, 1618 Anker, 1625 Tageskarte : cartes rangées
  dans un thème (bureau, circulation) dont l'exemple illustre un autre sens (œuvre, visite guidée,
  échelle, sonnette de porte, tournoi). Traduit selon l'exemple, les deux sens donnés quand la
  source les donne.
- 1501 Vertretung : le français dit « un remplaçant », l'allemand « eine Vertretung » ; rendu
  « un reemplazo ».
- 1740 Reiseführer : l'exemple est une personne ; la traduction donne aussi le livre.
